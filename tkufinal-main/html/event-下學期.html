P D C A

社課

我們桌遊社最例行性的活動，為了推廣桌遊活動，建立正確的桌遊知識與觀念。培養邏輯思考能力、反應能力、思維布局能力等各項素質提升。推廣正向的桌遊風氣每周二晚上會帶不同社員體驗不同的桌遊，讓社員們對桌上遊戲有較深入的認識，玩到更多平常較少接觸的桌遊品項，熟悉操作方式，同時也加深社員對本社團的歸屬感及情感的建立，建立一個桌遊同好彼此交流的平台。

下學期迎新

迎新活動以「實體角色扮演」（RPG）為主軸，旨在透過沉浸式的故事情境， 帶領新進社員體驗桌遊的多樣魅力。參與者將化身為劇中角色，藉由團隊合作、 謎題挑戰與策略思考，共同推動劇情發展。

P D C A

講座

本社為提升社員對桌遊產業的理解與視野， 特別邀請本校桌遊社第一屆優秀學姊—— 現為桌遊自媒體經營者「凱特的貓」擔任講者， 分享其觀察台灣桌遊設計圈的發展，以及德國、美國、日本等國際桌遊展覽的特色與趨勢， 藉此讓社員從玩家角色進一步認識桌遊的產業面與未來可能性，拓展多元學習經驗。

P D C A

卡卡頌桌遊比賽

卡卡頌是一款須觀察場上隨時變化的地形、 合理運用人力資源來得分的桌遊，因它能磨練社員資源分配與觀察分析能力， 因此選擇此款遊戲來當作比賽項目。

P D C A

桌遊周

本活動以「桌遊推廣」為核心，透過擺攤的形式提供桌遊體驗、 二手桌遊販售以抽獎活動，希望更多師生認識不只侷限於常見的幾款，讓大眾意識到桌遊也是可以鍛鍊身心、 培養團隊默契及練習溝通表達的娛樂項目。活動也希望降低桌遊入門門檻， 培養學生對桌遊的興趣，並且擴大桌遊的影響力。

P D C A

出包魔法師桌遊比賽

出包魔法師是一款需要計算場上與對手卡牌， 來合理猜測自己持有甚麼魔法的一款桌遊，過良性競爭， 讓社員在桌遊中相互較勁，不僅能增進彼此間的技術交流， 還能共同進步、磨練策略思維，進一步提升遊戲的掌握度與技巧。

P D C A

軍鬥牌比賽

軍鬥牌是一款結合策略思考、心理博弈與角色能力運用的卡牌桌遊， 遊戲過程強調玩家之間的資訊判斷、戰術選擇與臨場應變，兼具推理與資源配置，使每場對局皆能產生不同的互動體驗。
